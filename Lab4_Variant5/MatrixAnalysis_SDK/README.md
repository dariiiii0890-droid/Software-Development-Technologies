\# MatrixAnalysis SDK, версія API 1.0



\## Вимоги

\- Windows, архітектура x64, збірка Release, MSVC v143 (VS 2022)

\- C-ABI (extern "C"), стандартне cdecl-виклики, виключення через межу DLL не передаються



\## Склад пакунка

include/MatrixAnalysis.h - заголовок; lib/MatrixAnalysis.lib - імпортна бібліотека; bin/MatrixAnalysis.dll - бібліотека



\## Загальні правила

\- Матриця - одномірний масив double по рядках: елемент (i, j) = m\[i \* cols + j]

\- Розмір по кожній вимірності: від 1 до 100 (MATRIX\_MAX\_SIZE)

\- Пам'ять під вихідні параметри виділяє ВИКЛИКАЧ; бібліотека пам'ять не виділяє для користувача і нічого не звільняє

\- Вхідні масиви бібліотека не змінює

\- Значення з модулем менше 1e-9 вважаються нулем

\- Потокобезпечність: функції не мають глобального стану, можна викликати з різних потоків

\- Експортовані імена: determinant, inverse, rank, isSingular



\## Коди повернення

0 OK | 1 nullptr | 2 некоректний розмір | 3 NaN/Inf у матриці | 4 матриця вироджена (inverse)



\## Функції

\### int determinant(const double\* matrix, int n, double\* result)

Призначення: визначник матриці n x n.

matrix - масив n\*n double (не nullptr); n - від 1 до 100; result - вказівник на double (не nullptr).

Результат: \*result = det. Помилки: 1, 2, 3. При помилці \*result не змінюється.



\### int inverse(const double\* matrix, int n, double\* result)

Призначення: обернена матриця. result - буфер на n\*n double, виділений викликачем.

Помилки: 1, 2, 3, 4 (вироджена; вміст result тоді не визначений).



\### int rank(const double\* matrix, int rows, int cols, int\* result)

Призначення: ранг матриці rows x cols. Помилки: 1, 2, 3.



\### int isSingular(const double\* matrix, int n, int\* result)

Призначення: \*result = 1 якщо матриця вироджена (rank < n), інакше 0. Помилки: 1, 2, 3.



\## Порушення контракту

Якщо розмір буфера менший за вказаний (наприклад, масив з 4 елементів при n = 3), поведінка не визначена - бібліотека не може це перевірити.
